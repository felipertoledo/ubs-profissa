# UBS Profissa — vitrine

Página estática (GitHub Pages) que apresenta o UBS Profissa: pipeline de teleconsulta assistida, travas de segurança e resultados dos casos-teste. Os casos de demonstração são fictícios. A página traz dois casos verdadeiros, publicados com autorização escrita (do paciente no primeiro; da responsável legal no segundo, de uma adolescente), com datas relativas e sem serviço ou profissional nomeado; nenhum outro dado de paciente entra aqui.

Publicação: Settings → Pages → Deploy from a branch → `main` / root.
