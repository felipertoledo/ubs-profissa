# UBS Profissa — vitrine

Página estática (GitHub Pages) que apresenta o UBS Profissa: pipeline de teleconsulta assistida, travas de segurança e resultados dos casos-teste. Os casos de demonstração são fictícios. A seção "Caso real" traz um caso verdadeiro, publicado com autorização escrita do paciente, identificado por iniciais e com datas relativas; nenhum outro dado de paciente entra aqui.

Publicação: Settings → Pages → Deploy from a branch → `main` / root.
